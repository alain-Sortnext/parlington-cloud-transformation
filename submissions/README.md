# Submissions Directory

This directory contains your phase evidence for the Parlington simulation.

## Structure

```
submissions/
├── phase-1/    # Discovery & Portfolio Analysis
├── phase-2/    # Target Architecture & Landing Zone
├── phase-3/    # Networking, Security & Hybrid Cloud
├── phase-4/    # IaC, Automation & Operations
├── phase-5/    # Platform Engineering, Kubernetes & GitOps
├── phase-6/    # DevSecOps, CI/CD & Observability
├── phase-7/    # Database Architecture & Data Platform
├── phase-8/    # Migration, DR & FinOps
└── phase-9/    # Enterprise AI & Architecture Review Board
```

## What to submit per phase

After completing each phase in the Project Lab platform, commit your evidence here.
The GitHub URL you paste into the platform submission should point to the relevant
subdirectory or specific file in this directory.

## Naming convention

`submissions/phase-N/[deliverable-name].[ext]`

Examples:
- `submissions/phase-1/discovery-report.pdf`
- `submissions/phase-2/hld-landing-zone.drawio`
- `submissions/phase-4/terraform-vpc-module-screenshot.png`
- `submissions/phase-5/eks-cluster-screenshot.png`
